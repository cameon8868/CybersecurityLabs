# Linux Structure

### Linux - Cheat Sheet

| Команда | Описание |
|---|---|
| `man <tool>` | Открывает страницы руководства (man pages) для указанного инструмента. |
| `<tool> -h` | Выводит страницу справки инструмента. |
| `apropos <keyword>` | Ищет по описаниям в man pages вхождения заданного ключевого слова. |
| `cat` | Объединяет и выводит содержимое файлов. |
| `whoami` | Показывает имя текущего пользователя. |
| `id` | Возвращает идентичность пользователя. |
| `hostname` | Устанавливает или выводит имя текущей хост-системы. |
| `uname` | Выводит название операционной системы. |
| `pwd` | Возвращает имя рабочего каталога. |
| `ifconfig` | Утилита ifconfig используется для назначения или просмотра адреса сетевого интерфейса и/или настройки параметров сетевого интерфейса. |
| `ip` | Ip — утилита для отображения или управления маршрутизацией, сетевыми устройствами, интерфейсами и туннелями. |
| `netstat` | Показывает состояние сети. |
| `ss` | Ещё одна утилита для исследования сокетов. |
| `ps` | Показывает состояние процессов. |
| `who` | Показывает, кто вошёл в систему. |
| `env` | Выводит окружение или устанавливает и выполняет команду. |
| `lsblk` | Список блочных устройств. |
| `lsusb` | Список USB-устройств. |
| `lsof` | Список открытых файлов. |
| `lspci` | Список PCI-устройств. |
| `sudo` | Выполняет команду от имени другого пользователя. |
| `su` | Утилита su запрашивает соответствующие учётные данные пользователя через PAM и переключается на этот ID пользователя (по умолчанию — суперпользователь). Затем запускается оболочка. |
| `useradd` | Создаёт нового пользователя или обновляет информацию о новом пользователе по умолчанию. |
| `userdel` | Удаляет учётную запись пользователя и связанные файлы. |
| `usermod` | Изменяет учётную запись пользователя. |
| `addgroup` | Добавляет группу в систему. |
| `delgroup` | Удаляет группу из системы. |
| `passwd` | Изменяет пароль пользователя. |
| `dpkg` | Установка, удаление и настройка пакетов Debian. |
| `apt` | Высокоуровневая утилита управления пакетами командной строки. |
| `aptitude` | Альтернатива apt. |
| `snap` | Установка, удаление и настройка snap-пакетов. |
| `gem` | Стандартный менеджер пакетов для Ruby. |
| `pip` | Стандартный менеджер пакетов для Python. |
| `git` | Утилита командной строки системы контроля версий. |
| `systemctl` | Менеджер управления службами и systemd из командной строки. |
| `ps` | Выводит снимок текущих процессов. |
| `journalctl` | Запрашивает журнал systemd. |
| `kill` | Отправляет сигнал процессу. |
| `bg` | Переводит процесс в фоновый режим. |
| `jobs` | Показывает все процессы, выполняющиеся в фоновом режиме. |
| `fg` | Переводит процесс в передний план. |
| `curl` | Утилита командной строки для передачи данных на сервер или с сервера. |
| `wget` | Альтернатива curl, скачивающая файлы с FTP- или HTTP(s)-сервера. |
| `python3 -m http.server` | Запускает веб-сервер Python3 на TCP-порту 8000. |
| `ls` | Показывает содержимое каталога. |
| `cd` | Меняет каталог. |
| `clear` | Очищает терминал. |
| `touch` | Создаёт пустой файл. |
| `mkdir` | Создаёт каталог. |
| `tree` | Рекурсивно показывает содержимое каталога. |
| `mv` | Перемещает или переименовывает файлы или каталоги. |
| `cp` | Копирует файлы или каталоги. |
| `nano` | Текстовый редактор в терминале. |
| `which` | Возвращает путь к файлу или ссылке. |
| `find` | Ищет файлы в иерархии каталогов. |
| `updatedb` | Обновляет локальную базу данных для существующего содержимого системы. |
| `locate` | Использует локальную базу данных для поиска содержимого в системе. |
| `more` | Постраничный просмотрщик для чтения STDOUT или файлов. |
| `less` | Альтернатива more с большими возможностями. |
| `head` | Выводит первые десять строк STDOUT или файла. |
| `tail` | Выводит последние десять строк STDOUT или файла. |
| `sort` | Сортирует содержимое STDOUT. |
| `grep` | Ищет конкретные результаты, содержащие заданные шаблоны. |
| `cut` | Удаляет участки из каждой строки файлов. |
| `tr` | Заменяет определённые символы. |
| `column` | Утилита командной строки, форматирующая входные данные в несколько столбцов. |
| `awk` | Язык сканирования и обработки шаблонов. |
| `sed` | Потоковый редактор для фильтрации и преобразования текста. |
| `wc` | Выводит количество строк, слов и байтов для заданного ввода. |
| `chmod` | Изменяет права доступа к файлу или каталогу. |
| `chown` | Изменяет владельца и группу файла или каталога. |
